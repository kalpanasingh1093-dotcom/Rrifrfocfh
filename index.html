Privacy Policy & Student Data Charter

School-Safe Charter

CivicPulse Data Handling Plan • Zero Third-Party Trackers

Commitment to Students, Educators & Parents

CivicPulse is designed for educational learning and social awareness. We never sell student data, never run behavioral ads, and never request sensitive personal contact details.

1. Data Minimization & Strict Non-Collection

  • Stored for Learning Progress: Chosen display username, grade selection, difficulty tier, XP points, level (1–100), streak count (starting at 0), and completed modules/questions.
  • Never Collected: Real legal names, home addresses, phone numbers, email addresses, government IDs, camera/microphone audio, or exact GPS coordinates.

2. Storage Architecture & Graceful Offline Fallback

When Cloud Firestore is configured in the host environment, user records are scoped under an authenticated user path (/artifacts/{appId}/users/{userId}/profiles/{username}). If no Firebase configuration is present or the device is offline, CivicPulse safely runs using in-memory session state with zero errors.

3. Zero External CDNs & Zero Advertising Trackers

All styles, icons, civic background patterns, passages, and question banks are embedded directly inside civicpulse_app.html with no external CSS frameworks, icon CDNs, or ad-tracking scripts.

4. Fresh Login Reset & One-Click Record Erasure

Every time the login form is submitted, XP and streak start fresh at 0. You can also permanently erase your current session/cloud record at any time using the button below.
